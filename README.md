# Swift-stemmer
An algorithm for suffix stripping Porter Stemmer
Porter's stemmer for Swift

## How to use ##

1. Usage
   ```Swift
   let myword = "running"
   print("running -> \(stemWord(myword))")
   print("flies -> \(stemWord("flies"))")

   
2. Compile / Run
   ```
   swiftc FileSwift-stemmer.swift
   ./FileSwift-stemmer
   or FileSwift-stemmer.exe
